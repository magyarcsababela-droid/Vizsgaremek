# ComputerParts vizsgaremek

- Fejlesztők
  - *Magyar Csaba Béla*
  - *Rebe Dániel Zsombor*

A projekt célja, hogy egy olyan weboldalat hozhassunk létre, amelynek segítségével a felhasználó egy letisztult, bármely korosztály számára nehézségek nélkül használható oldalon tudja összeállítani a számára megfelelő számítógép konfigurációt, az összeállított konfigokat pedig a saját profiljába elmentse és onnan kezelje.

Feladatok felosztása:
- Magyar Csaba
  - API fejlesztése, minden táblára lebontva (NEM Generic API-val készült program)
  - Adatbázis szerkezet létrehozása és továbbfejlesztése
  - Főoldal kialakítása (design-t nem bele értve)
  - Projekt rendszerezése
  - Admin panel létrehozása
  - Fejlesztői tesztelés

- Rebe Dániel
  - Alap API létrehozása, minden táblát külön kezelve (NEM Generic API-val készült program)
  - Frontend összekötése a Backend-del
  - Frontend design kialakítása
  - Összes Frontend oldal átültetése C-Sharp (C#) környezetbe
  - Adatbázis szerkezet rendszerezése
  - Alap projekt létrehozása
  - Felhasználói tesztelés (mind egyszerű felhasználó, mind admin téren)
